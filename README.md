# AI Engineer's Handbook: companion files

Code, synthetic data, run records and guides for the book *AI Engineer's Handbook:
Practical Agent Systems, Resource Engineering, Evaluation, and Scientific Discovery*
by Kyeong-Sun Kim.

- `examples/ref01_expense_report/`: chapter E1 (instrumented workflow, completion checker)
- `examples/mm01_screen_grounding/`: chapter Q1 (multimodal prompting experiment)
- `reviews/evidence/`: the run records the book's numbers come from
- `guides/`: dated setup guides; `references/`: source register

Requirements: Python 3.12 or later (standard library only). Optional: Ollama.
Start with `examples/ref01_expense_report/` and run `python -m unittest discover -s tests`.
